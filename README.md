# DataMining
数据挖掘大作业

## 1. 聚类任务 (Clustering Task)

在本节中，我们针对给定的图像数据集进行无监督聚类分析。数据集包含 cable, tile, bottle, pill, leather, transistor 共 6 个类别，每类 100 张图片，总计 600 张图片。我们的目标是在不使用标签信息的情况下，将图像正确地划分到各自的语义类别中。

## 2. 图像异常检测任务 (Image Anomaly Detection)

在本节中，我们针对工业检测场景（Hazelnut 和 Zipper）设计并实现了一种基于重构误差的图像异常检测算法。


## 3. 时间序列预测任务 (Time Series Prediction)

本节利用德国耶拿气象站数据，根据过去 2 小时（12个时间步）的气象指标，预测下一时刻的室外温度（OT）。



## 4. 无监督疾病判断任务 (Unsupervised Disease Diagnosis)

本节利用甲状腺疾病数据集 (Thyroid)，设计基于 **自动编码器** 的无监督异常检测模型。
